# Learning Path and Course Expectations

This course develops disciplined open-source investigation capability. It is not a catalogue of websites or shortcuts. Learners must be able to define an intelligence requirement, collect proportionately, preserve provenance, assess reliability, analyse competing explanations and communicate findings with explicit confidence.

## Course outcomes

By the end of the programme, you should be able to:

1. Translate a broad request into intelligence requirements and collection questions.
2. Apply legal, ethical, privacy and evidential guardrails before collecting information.
3. Build a documented collection plan using public and authorised sources.
4. Search systematically across search engines, public records, social platforms and technical infrastructure sources.
5. Validate identities, dates, locations, relationships and digital artefacts through corroboration.
6. Maintain an investigation log, source register and evidence record.
7. Separate fact, assessment, inference and unresolved uncertainty.
8. Produce an executive-ready OSINT report with defensible confidence statements.

## Recommended sequence

| Phase | Focus | Evidence of competence |
|---|---|---|
| Orientation | Scope, conduct and safe learning practice | Signed learner declaration |
| Foundations | OSINT, intelligence cycle and requirements | Knowledge check |
| Planning | Scope, hypotheses, collection plan and OPSEC | Investigation plan |
| Collection | Search, people, social, technical and media sources | Source register |
| Processing | Normalisation, preservation and provenance | Evidence log |
| Analysis | Corroboration, timelines, link analysis and confidence | Findings matrix |
| Reporting | Findings, caveats, recommendations and appendices | Final report |
| Assessment | Controlled investigation sprint | Capstone submission |

## Learning model

Each module uses the same cycle:

- **Learn:** Study the concept and worked examples.
- **Apply:** Complete a controlled exercise.
- **Record:** Capture actions, sources and decisions.
- **Reflect:** Identify limitations and alternative explanations.
- **Assess:** Complete a knowledge check or practical deliverable.

## Completion standard

A learner completes the course when all required lessons, knowledge checks, practical activities and the final investigation sprint have been completed. Practical work is assessed on method, documentation, proportionality, corroboration and reporting quality—not merely whether the learner found the expected answer.

:::warning Controlled learning environment
Use only the supplied scenarios, data and authorised targets. Do not test techniques against private individuals, live accounts, restricted systems or unlawfully obtained data.
:::
