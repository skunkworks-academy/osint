# Assess without amplifying harm

## Sensitivity classes

- **PII:** names, addresses, dates of birth, phone numbers and identifiers.
- **Credentials:** passwords, tokens and session artefacts.
- **Operational:** travel patterns, contacts, roles and calendars.
- **Contextual:** affiliations, services and behavioural routines.

Individually low-sensitivity facts can create a high-confidence targeting profile when aggregated.

## Safe handling rules

- Redact unique identifiers in screenshots, notes and reports.
- Describe exposure rather than republishing the exposed material.
- Store only what is necessary to answer the SIR.
- Record handling restrictions and authorised recipients.
- Escalate credentials or protected information immediately; do not inspect or test them.
