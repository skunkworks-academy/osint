# OSINT fundamentals

OSINT is publicly available information collected and analysed with purpose. It is a disciplined methodology that can support other intelligence disciplines.

OSINT is not hacking, credential testing, passive browsing without tasking, or a replacement for HUMINT, FININT, COMINT, GEOINT or IMINT.

## Data, information and intelligence

- **Data:** raw observations or artefacts.
- **Information:** data placed into context.
- **Intelligence:** verified and analysed information that answers a defined requirement and supports action.

A broken or unavailable tool should not break the analyst. The methodology must remain stable when tools change.

:::note Boundary principle
Public availability does not automatically make collection or reporting lawful, ethical or necessary.
:::
