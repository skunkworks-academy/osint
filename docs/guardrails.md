# Lawful, ethical and evidentially sound OSINT

Before any search begins, establish the operating model.

## Non-negotiables

- Collect only from lawful, authorised, public sources.
- Mask personal identifiers unless strictly necessary.
- Never validate stolen credentials or bypass access controls.
- Record source, time, context and confidence for every finding.
- Report risk without amplifying harm.

:::danger Stop rule
If an activity resembles access, authentication, evasion or exploitation, stop and escalate.
:::

## Collection decision test

Before collecting an artefact, ask:

1. Is the source public?
2. Is the action passive?
3. Is the output necessary for an intelligence requirement?
4. Can it be recorded without creating additional harm?
5. Is the handling method authorised and documented?
