# Collect in depth without losing control

## 4. Use platforms
Apply approved IP/domain lookup, reverse-image, account-discovery and public-record tools. Tool output is a lead, not proof.

## 5. Timestamps and metadata
Capture publication time, observation time, file metadata and surrounding context. Normalize time zones before building a chronology.

## 6. Real-time collection
Monitor authorised public channels during the defined event window. Record what changed and when; avoid contact or interference.

## 7. Breach exposure
Use approved exposure sources only to assess whether an identifier appears in known datasets. Never retrieve, test or validate credentials.

Maintain an investigation log containing source, URL, capture time, artefact description, SIR relevance, sensitivity and confidence.
