# Scope, baseline and query design

## 1. Define scope
Record goals, key information required, possible offences, authority, boundaries, exclusions and reporting thresholds.

## 2. Initial research
Use search engines, public records, official sources and known repositories to establish a baseline. Separate confirmed facts, claims requiring verification and unknowns.

## 3. Tailor queries
Build keywords, username variants, date ranges, role titles, aliases and advanced-search combinations that directly support the SIRs.

:::tip Decision gate
Collection begins only after scope, authority and the investigation-log structure are agreed.
:::
